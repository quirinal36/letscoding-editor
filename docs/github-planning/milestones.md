## M1 — 정적 웹 편집·서버 저장·격리 미리보기

- 기간: 2~3주차 / 2주
- 주요 에픽: E-02, E-03, E-04
- 완료 기준: 새 프로젝트→HTML 작성→자동 저장→상대 경로 자산 포함 미리보기→다른 기기 재열기가 동작한다. 파일 업로드·ZIP 가져오기·키보드·호환성 및 격리를 검증한다.
- 후보: I-014, I-015, I-016, I-017, I-018, I-019, I-020, I-021, I-022, I-023, I-024

## M2 — AI 읽기·쓰기·승인

- 기간: 4~5주차 / 2주
- 주요 에픽: E-05, E-06 일부
- 완료 기준: 버튼 색 변경 요청→diff→승인→저장→미리보기가 동작하고 승인 전 원본은 변하지 않는다. 삭제/이름 변경은 항상 확인한다. AI 비용 차단과 데이터 정책이 켜져 있다.

## M3 — 멀티모달·모델·사용량

- 기간: 6주차 / 1주
- 주요 에픽: E-06
- 완료 기준: 최대 3장 이미지 첨부→비전 응답, 생성 이미지→프로젝트 파일 반영, 허용 모델 선택과 토큰/USD 기록 및 일일 차단이 동작한다. 이미지 생성 제외는 별도 범위 결정이 필요하다.
- 후보: I-032, I-033, I-034

## M4 — 라운지 배포·재배포

- 기간: 7~8주차 / 2주
- 주요 에픽: E-07, E-08

## M5 — 안정화·파일럿·출시

- 기간: 9주차 / 1주
- 주요 에픽: E-09
- 완료 기준: 정해진 출시 범위의 수용 기준, 전체 E2E, 접근성, 관측, 출시 점검 E가 통과하고 학생 5명 파일럿 결과 및 안내 문서를 남긴다.
- 후보: I-038, I-039, I-040, I-041, I-042, I-043

## 의존 관계와 출시 게이트

M0 결정/검증·Auth/VFS → M1 편집/프리뷰 → M2 AI 승인(최소 예산 차단 선행) → M3 멀티모달 → M4 배포 → M5 출시다. 라운지 작업은 M0 계약 확보→M2부터 구현 병행→M4 통합 완료로 잡는다. 법·동의·결제·보존 정책은 출시 전 검토가 필요하므로 준비는 앞당긴다.

원문 9주는 구현 보장이 아닌 추정치다. M0는 실험·결정 작업도 많고 M5에 1주 파일럿과 결함 수정이 함께 있어 여유가 없다. 최초 등록 시 날짜를 임의로 정하지 않고 담당/가용시간/파일럿 일정을 반영한다.
